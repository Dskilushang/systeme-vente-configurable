# Système de Vente en Ligne Configurable – Démo

Cette démo présente une boutique en ligne simple (HTML + CSS).

- Nom de la boutique : Boutique Aacbusiness
- Produits : chemises, pantalons, costumes
- Contact : téléphone, WhatsApp, email, adresse

Cette version est statique (pas de PHP, pas de base de données).  
Elle est conçue pour être hébergée sur GitHub Pages.

## Structure

- `index.html` : page principale
- `style.css` : styles et couleurs

## Personnalisation

Pour changer :

- Le nom de la boutique → modifier `index.html`
- Les couleurs → modifier `style.css` (variables `--primary-color`, `--secondary-color`)
- Les contacts → modifier la section Contact dans `index.html`
